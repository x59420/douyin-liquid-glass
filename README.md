# dydock · 抖音底栏液态玻璃

一个面向抖音 Android 客户端的 LSPosed 模块：**把四个主页面底部导航栏替换成悬浮液态玻璃 Dock**，尽量保留抖音原有的布局和点击逻辑。

> 当前源码版本：**0.1.12**
>
> APK 下载：**[GitHub Releases](https://github.com/x59420/douyin-liquid-glass/releases)**
>
> 自动构建：每次推送到 `main` 且构建成功后，GitHub Actions 会自动创建一个带 APK 的 Release。

---

## 功能一览

- 将官方底部导航栏显示替换为两块悬浮玻璃：
  - 左侧：一整块长条玻璃，显示 4 个导航图标
  - 右侧：独立的圆形「＋」玻璃按钮
- 左侧四项胶囊贴左侧安全边距，右侧「＋」独立贴右侧安全边距，中间保留明确间距。
- 保留官方底栏的布局和点击目标，点击玻璃上的位置会转发给对应的官方导航项。
- 从宿主原有导航项读取未读状态，并在玻璃 Dock 上显示角标。
- 玻璃 Dock 在首次识别后固定在屏幕底部位置，不再逐帧追随原生 Dock；原生节点只用于转发点击和读取角标。
- 支持按住导航项、左右拖动和松手弹簧回位。
- 玻璃背景优先采样宿主界面内容；不支持实时着色器的系统会使用磨砂效果回退。

## 修改范围

**本项目只处理抖音四个主页面底部 Dock（首页、朋友、消息、我）。**

| 区域 | 行为 |
| --- | --- |
| 首页、朋友、消息、我的底部导航栏 | 替换显示为液态玻璃 Dock |
| 顶栏、搜索栏 | 保持抖音原样 |
| 信息流、视频内容 | 不主动修改 |
| 评论区、聊天页、消息页 | 保持抖音原样 |
| 个人页、设置页、弹窗 | 保持抖音原样 |

模块会识别四个主页面共用的底部导航栏；四个主 Tab 均显示玻璃 Dock。菜单弹层或进入覆盖式个人主页等场景会临时收起玻璃 Dock；返回主页面后重新识别导航节点并恢复玻璃 Dock，原生 Dock 保持隐藏。

> 说明：抖音会持续更新，内部界面结构可能变化。识别逻辑不保证兼容所有版本，实际效果需要在目标设备上验证。

## 液态玻璃与动画

### 玻璃效果

- 背景采样与裁切
- 圆角区域的折射效果
- 边缘 RGB 色散
- 高光、表面着色和阴影
- 按压、拖动时的透镜变化

### Dock 交互

- 点击导航项：切换到对应页面
- 长按导航项：进入选中状态
- 左右拖动：选中透镜跟随手指移动
- 松开：弹簧动画回到最近的导航位置
- Dock 会持续跟随官方底栏的位置变化

交互和着色器实现参考了文末列出的开源项目；本项目并非对参考项目的完整逐行移植。

## 系统要求

- Android **8.0（API 26）及以上**
- 已安装并正常运行 LSPosed
- LSPosed 环境支持 Xposed API 82 或兼容接口
- 抖音 Android 客户端

部分液态折射效果使用 Android 13（API 33）及以上提供的 RuntimeShader / AGSL：

- Android 13 及以上：可使用 RuntimeShader 折射效果
- Android 8.0–12：使用磨砂玻璃回退效果，视觉效果会有所不同

## 安装与启用

1. 从 [Releases 页面](https://github.com/x59420/douyin-liquid-glass/releases) 下载最新 APK。
2. 在 Android 系统中安装 APK。
3. 打开 LSPosed，找到并启用 **dydock** 模块。
4. 确认模块作用域包含抖音（包名：`com.ss.android.ugc.aweme`）。
5. 强制停止抖音，再重新打开。

本模块没有桌面启动图标或独立设置界面。安装后需要在 LSPosed 中管理模块状态。

## 构建

项目使用自定义 Shell 脚本构建，不使用 Gradle，也不要求 Android Studio。

### 本地环境

- JDK 17
- Android SDK
- Android SDK Platform（例如 android-35）
- Android SDK Build Tools（例如 35.0.0）
- 可用的网络连接（首次构建需要下载 Xposed API jar）

### 构建命令

```bash
ANDROID_HOME=~/android-sdk bash build.sh
```

成功后 APK 位于：

```
out/dydock-0.1.2.apk
```

### GitHub Actions

工作流文件：`.github/workflows/build-apk.yml`

推送到 `main` 后会自动：

1. 配置 JDK 和 Android SDK
2. 执行 `build.sh`
3. 上传 APK 构建产物
4. 创建 GitHub Release，并把 APK 附加到发行版

也可以在仓库的 **Actions** 页面手动运行工作流。构建产物 Artifact 是临时下载项；正式下载建议使用 **Releases** 页面。

### 签名注意事项

仓库中的 `keystore/dydock.jks` 用于给 APK 签名。**后续构建必须继续使用同一份 keystore**，不要随意删除或重新生成，否则新 APK 可能无法覆盖安装在设备上的旧版本。

请妥善保管签名文件，不要把它发送给他人或上传到无关位置。

## 版本记录

### 0.1.12

- 修复玻璃层临时脱离窗口后显隐轮询永久停止的问题；Activity 返回时自动重新挂回原窗口。
- 仅在 Activity 真正销毁时释放背景资源，页面转场期间保留玻璃背景数据。
- 点击时改为按压力等比缩放 Dock 面板，避免上下边缘过度外扩。
- 长按透镜对齐 Tieba 的 56dp 基础高度与 78/56 放大比例，保持横向胶囊宽高比例。

### 0.1.11

- 玻璃 Dock 首次识别后固定屏幕位置，不再依赖原生 Dock 的显示状态；菜单/个人主页只控制玻璃层显隐。
- 移除布局变化时的底栏位置追踪，显隐检测取消重复的整屏覆盖扫描；原生节点不可用时低频重新绑定点击目标.

### 0.1.10

- 点击面板外扩改为上下左右等距，不再附加垂直偏移；点击动画圆角随胶囊外扩保持一致。
- 长按液滴恢复横向胶囊比例，限制为最多 6% 的整体放大，不再因拖动速度变成宽条或近圆形。
- 同步收敛图标行和角标的按压放大幅度。
- 菜单或个人主页切换时若抖音替换/临时隐藏原生导航节点，轮询器会重新识别并接管；返回后恢复玻璃 Dock，原生 Dock 始终透明。

### 0.1.8

- 显隐轮询增加覆盖层脱离窗口时的原生底栏恢复保护，并在 Dock 再次显示时等待本次真实绘制完成后才隐藏原生底栏。
- 个人资料页识别改为组合特征判断，降低信息流普通“关注/作品”文案造成的误隐藏。
- 修正 TextureView 背景采样：按 Dock 区域裁切视频画面，并使用缩小采样控制内存与刷新开销。
- 增强长按液滴的横向拖动拉伸与回弹偏移；液滴目标宽度保持略收窄，Dock 基础几何不变。

### 0.1.2

- 将 Dock 胶囊高度和底边定位恢复为 0.1.0 的数值，保持原先位置与尺寸。
- 只有明确识别到首页处于选中状态时才显示玻璃 Dock；朋友、消息、我的等页面恢复抖音原生底栏。
- 增加对首页菜单/展开面板的连续检测，打开菜单时收起玻璃 Dock，关闭后按首页状态恢复。
- 保留 0.1.1 的闪现修复与透明手势导航栏设置，顶部左右菜单按钮及其他 UI 不做改动。

### 0.1.0

- 修正长按/拖动透镜形状：改为与 Dock 一致的横向圆角胶囊，不再绘制成圆球；宽高分别跟随液滴弹簧形变。
- 页面显隐改为同时检查首页选中状态、窗口焦点和展开面板；进入非首页、打开首页左上角菜单或“我的”页右上角菜单时收起自定义 Dock，返回首页后恢复。
- 增加独立显隐轮询，补足 PopupWindow 菜单不触发内容区布局回调的情况。

### 0.0.9

- 对齐 Tieba 的长按液滴尺寸：透镜以 56dp 为基准，按压时按 78/56 的比例膨胀，允许自然超出左侧胶囊边缘。
- 移除选中透镜额外绘制的外部阴影和人工描边，保留液态玻璃自身的折射、深度与高光。
- 左侧玻璃胶囊、图标行和角标围绕中心同步放大；右侧红色「＋」保持独立，不跟随左侧透镜放大。

### 0.0.8

- 左侧四项 Dock 改为左侧安全边距对齐，右侧「＋」独立停靠在右侧，不再把左胶囊居中后再把「＋」挤到边缘。
- 按屏幕可用宽度动态扩大四个 tab 槽位，窄屏保留独立按钮间距并自动收敛。
- 「＋」改为饱和红色实体玻璃外观，增加悬浮阴影、顶部高光和亮色边缘，图标固定为白色。

### 0.0.7

- 修复拖动松手后释放弹簧可能停止继续调度的问题，确保透镜在落位后完成收缩回弹。
- 将 Dock 首次背景采样移到实际玻璃区域确定之后，并在采样时临时隐藏原生 Dock 图标，避免初始磨砂块和原生图标残影。
- 将 Android 13 RuntimeShader 调用隔离到延迟加载的适配类，避免 API 26–32 在加载玻璃绘制类时提前解析新系统类型。
- 清理 Dock 覆盖层离开窗口时的 Choreographer 回调与背景位图。

### 0.0.6

- 将贴吧参考项目的多通道阻尼运动移植到选中透镜：压力、宽高、速度、发光与拖动偏移独立弹簧。
- 收紧底栏识别范围，排除相关搜索等搜索结果行，避免误接管非 Dock 区域。

### 0.0.5

- 调整 Dock 排版：左侧 4 个导航图标区域水平居中，「＋」按钮靠近右侧。
- 更换为 24dp 实心导航图标。
- 补齐长按和左右拖动交互，松手后以弹簧动画回到最近位置。
- Dock 位置改为逐帧跟随官方底栏，改善侧栏展开等平移动画中的同步表现。
- 优化玻璃分区与裁切，减少玻璃绘制越界。
- 优化页面切换时的识别与恢复逻辑。

### 0.0.4 及更早版本

历史版本曾尝试对顶栏和聊天区域添加玻璃效果。当前代码已收敛为**只处理底部 Dock**，这些区域不再由模块添加玻璃层；底栏识别同时排除搜索结果行。
