# dydock · 抖音底栏液态玻璃

只给**抖音的底栏**换一层悬浮液态玻璃 · LSPosed 模块

> 当前版本：**0.0.1**（重新开始的第一版）· APK 见 [Releases](../../releases)
>
> 上一代那套（全局扫描 + 到处套玻璃 + 设置界面）整条线推倒重做，仓库也重建了。
> 这一版只干一件事：**底栏**。

---

## 是什么样

底栏那一条被拆成两块悬浮玻璃，位置还在官方原来的位置（系统手势条上方）：

```
┌──────────────────────────────────────────────┐
│                                              │
│                  （页面内容）                  │
│                                              │
│   ╭───────────────────────────╮              │
│   │  ⌂     ⚇      ▢      ⊙   │      ╭───╮   │
│   ╰───────────────────────────╯      │ ＋ │   │
│                                      ╰───╯   │
│  ────────────── 系统手势条 ──────────────     │
└──────────────────────────────────────────────┘
```

- 左边一块玻璃装 **4 个控件**，原来的「首页 / 朋友 / 消息 / 我」**文字换成图标**
- 右边 **＋（发布）单独一块** 圆形玻璃
- 宽度按内容收窄（4 个图标不用铺满整屏，铺满就会扁得没法看）
- 按住选中块会跟手、越界带阻力、松手弹簧回弹到最近一格并切过去（照 Kyant 的 `LiquidBottomTabs`）

## 只改了什么

| | |
| --- | --- |
| 改 | 底栏那一条（官方底栏的子项位置、点击都保留，只是画面换成玻璃） |
| 不改 | 顶栏、信息流、评论区、消息页、个人页、设置页、任何弹窗 |
| 不改 | 页面布局、窗口 inset、系统的深浅色 |
| 没有 | 设置界面、桌面图标、通知、常驻服务 |

「别的画面还是官方原版」是刻意做出来的：这一版**只在认出底栏的那个 Activity 里装一次**，
认不出来就整个什么都不做，不会去碰别的页面。

## 为什么这次不会到处叠黑块

上一版的玻璃是往**整棵视图树**上套的：扫到一个控件就在它上面铺一块玻璃，
每块玻璃都要去抓一份背景。抖音首页的视频画面在 `SurfaceView` 的独立图层里，
`View.draw()` 根本抓不到，抓到的是黑 —— 于是每块玻璃底下都是一块黑，
页面一切换，那些黑块还没跟上，看着就是「到处叠黑块」。

这一版的做法：

1. **只采一条**：背景只采底栏那一条（`content` 根视图往下画），不采整屏
2. **视频单独抓**：树里找到 `SurfaceView` / `TextureView`，用 `PixelCopy` 只抓它
   在底栏那一条里的那一块，然后**把 UI 层里那块挖空**再叠起来 —— 视频就不会被
   容器自己的深色底盖住
3. **采集根是 `content`**，玻璃挂在 `DecorView` 上，两者是兄弟节点 ——
   玻璃永远不会把自己画进自己的背景里（不需要「采集时把玻璃藏起来」那种会闪一下的招）
4. **视频铺满时直接跳过画树**：抖音首页那一整条都是视频，就不用每 1.2 秒重画一遍信息流，省电也省卡顿
5. **没有背景可用时只画一层极淡的白雾**，绝不拿深色打底

## 安装

1. 需要 **LSPosed**（Xposed API 82 及以上；已内置作用域 `com.ss.android.ugc.aweme`，
   启用时一般会自动勾上抖音）
2. 安装 `dydock-0.0.1.apk`
3. LSPosed 里启用模块 → 确认作用域勾了抖音 → 强制停止抖音 → 重新打开

> 本版**没有桌面图标**，装完在桌面看不到是正常的，去 LSPosed 里找 `dydock`。
>
> 和上一代同一个包名、同一个签名（`versionCode 100` 已高于老的 16），可以直接覆盖安装。

### 日志

出问题看 **LSPosed 日志**，tag 是 `dydock`：

```
dydock 0.0.1 装载进宿主
背景视频层 1 个（SurfaceView）
底栏已接管：4 个图标 ＋ 独立一块，底栏 1080x168（XXX）
```

- 只有「装载进宿主」没有「底栏已接管」→ 这次没认出底栏（见下）
- 有「底栏已接管」但位置不对 → 把日志和抖音版本号发到 Issues

## 已知限制

- 只在**认得出官方底栏**的版本上工作。认法不看类名（抖音天天混淆），看结构：
  屏幕下方 26%、高 34–110dp、宽 ≥55%、有 4–6 个横向排列的可点子项。认不出来就整个不动，
  不会乱改页面。
- **没有真机验证过观感**：编译、包结构、签名、dex、着色器都验过了，但折射出来好不好看、
  底栏宽度合不合适，得你上手看一眼。位置/宽度不对就把截图和抖音版本号发上来。
- 抖音自己如果有底栏的滚动隐藏动画，玻璃不跟（钉在官方位置上）。
- 角标（未读红点）这一版**不画**：底栏画面是自己画的，角标得从宿主那边读，留到下一版。
- AGSL 折射需要 **Android 13+**；12 及以下退回「模糊 + 高光」的磨砂观感。

## 构建

不需要 Gradle、不需要 Android Studio：

```bash
# 需要 JDK 17、Android SDK（build-tools + platforms）
ANDROID_HOME=~/android-sdk bash build.sh
# 产物：out/dydock-0.0.1.apk
```

第一次跑会自动下 Xposed API 的 jar；仓库里已经带了签名 `keystore/dydock.jks`
（口令 `dydock2026`）——**换签名以后就盖不上旧版了**。
