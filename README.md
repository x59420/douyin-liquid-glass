# dydock · 抖音液态玻璃

给**抖音的底栏和顶栏**换一层悬浮液态玻璃 · LSPosed 模块

> 当前版本：**0.0.5** · APK 见 [Releases](../../releases)

---

## 是什么样

```
┌──────────────────────────────────────────────┐
│ ╭──╮  ╭───────────────────────────╮  ╭───╮   │
│ │ ☰│  │  关注   推荐   朋友   直播  │  │ ⌕ │   │
│ ╰──╯  ╰───────────────────────────╯  ╰───╯   │
│                                              │
│                  （页面内容）                  │
│                                              │
│          ╭───────────────────╮╭────╮         │
│          │  ⌂    ⚇    ▢    ⊙  ││ ＋ │         │
│          ╰───────────────────╯╰────╯         │
│  ────────────── 系统手势条 ──────────────     │
└──────────────────────────────────────────────┘
```

**顶栏三块**：左边展开 / 中间整条 tab / 右边搜索，各一块悬浮玻璃，三块之间留空隙。

**底栏两块**：左边一块装 4 个图标、**水平居中**，右边 ＋ 一块**紧贴着它**（中间只留 3dp 的缝）。

聊天页也一样按「块」来分：

```
┌──────────────────────────────────────────────┐
│ ╭──╮  ╭─────────────────╮  ╭───────────╮    │
│ │ ←│  │ 头像  昵称       │  │  ⋯   ⌕    │    │
│ ╰──╯  ╰─────────────────╯  ╰───────────╯    │
│                                              │
│                  （聊天内容）                  │
│                                              │
│  ╭────────────────────────╮  ╭─────────╮    │
│  │  发消息…               │  │ ⊙ ⊚ ⊕  │    │
│  ╰────────────────────────╯  ╰─────────╯    │
└──────────────────────────────────────────────┘
```

- 聊天顶栏：**返回一块、头像+昵称一块、右侧一块**
- 聊天底部：**输入条一块、右边三个控件一块**

- 底栏比官方那一条大一圈，也往上抬高了一点，手势条那一带是透明的（才有悬浮感）
- 「首页 / 朋友 / 消息 / 我」的文字换成图标（0.0.5 换成一套实心图标，24dp，放大也不发虚）
- 出现时整组从下浮上来淡入，图标依次亮起
- **长按 → 选中的那一块放大成透镜、整条鼓一下，图标跟着放大**
- **按住往左右拖 → 透镜跟手走，拖得越快沿运动方向拉得越长（最大 20%），松手弹到最近一格**，
  放大要等它快到位才收回去 —— 读起来是一个连贯动作，不是「滑一下、再单独缩一下」
- 点一下就切换，点哪儿就是哪儿；拖动中撒手则落到手指停下的那一格
- 整组位置**每帧跟官方底栏对齐**：展开个人页侧栏那种底栏滑过去的动画，玻璃跟着一起滑，不滞后

## 只改了什么

| | |
| --- | --- |
| 改 | 底栏那一条（子项位置、点击都保留，只是画面换成玻璃）、顶栏三块的底色、聊天页顶栏和输入条那两行的底色 |
| 不改 | 信息流、评论区、消息页、个人页、设置页、任何弹窗 |
| 不改 | 页面布局、窗口 inset、系统的深浅色；顶栏的文字图标还是官方自己画的 |
| 没有 | 设置界面、桌面图标、通知、常驻服务 |

**只在这个 Activity 认得出底栏时装**，认不出来就什么都不做。

首页的 dock 只出现在首页那一条上：带输入框的底部输入条不会被误认成 dock，
同一个 Activity 里叠上来一整屏页面时，dock 的玻璃也会跟着收起来。

顶栏和聊天页那两行玻璃是**只换底色**：宿主什么时候把底色重设回去，
模块下一秒就补回来；离开这一页 / 行结构变了就把原来的底色还回去 —— 不留残影。

## 玻璃背景怎么来的

1. **只采一条**：底栏只采底栏那一条，顶栏只采顶上那一条，不采整屏
2. **视频单独抓**：树里找到 `SurfaceView` / `TextureView`，用 `PixelCopy` 只抓需要的那一块，
   再把 UI 层里那块挖空叠起来 —— 视频不会被容器自己的深色底盖住
3. **采集根是 `content`**，底栏玻璃挂在 `DecorView` 上，是兄弟节点，不会把自己画进背景
4. **顶栏玻璃是当背景用的**，采集时临时静音，不会自己糊自己
5. **采不到画面时画一块能看见的磨砂玻璃**，绝不糊一层几乎透明的白 ——
   以前「dock 看起来不见了」就是这种白底白图标

## 安装

1. 需要 **LSPosed**（Xposed API 82 及以上；已内置作用域 `com.ss.android.ugc.aweme`，
   启用时一般会自动勾上抖音）
2. 安装 `dydock-0.0.5.apk`
3. LSPosed 里启用模块 → 确认作用域勾了抖音 → 强制停止抖音 → 重新打开

> 本版**没有桌面图标**，装完在桌面看不到是正常的，去 LSPosed 里找 `dydock`。
>
> 和 0.0.1 同一个包名、同一个签名（`versionCode 500`），可以直接覆盖安装。

## 已知限制

- 认底栏、认顶栏都**不看类名**（抖音天天混淆），看结构。认不出来就整个不动，不会乱改页面。
- 抖音自己有底栏的滚动隐藏动画时，玻璃跟着底栏一起动；底栏被宿主整条藏起来时玻璃也一起收。
- AGSL 折射需要 **Android 13+**；12 及以下退回「模糊 + 高光」的磨砂观感。

## 构建

不需要 Gradle、不需要 Android Studio：

```bash
# 需要 JDK 17、Android SDK（build-tools + platforms）
ANDROID_HOME=~/android-sdk bash build.sh
# 产物：out/dydock-0.0.5.apk
```

第一次跑会自动下 Xposed API 的 jar；仓库里已经带了签名 `keystore/dydock.jks`
（口令 `dydock2026`）——**换签名以后就盖不上旧版了**。

## 更新日志

### 0.0.5
- **底栏排版**：左边那块装 4 个图标的**水平居中**，＋ **紧贴着它右边**（只留 3dp 的缝）。
  以前是整组居中，左边的块被 ＋ 挤得偏左，看着是歪的。
- **补上长按滑动**（手感照 KernelSU 的 `DampedDragAnimation` 和 Kyant 的 `LiquidBottomTabs`
  的弹簧参数）：
  - 按住：选中块放大成一块透镜（1.16 倍），整条鼓一下，底下的图标跟着放大
  - 拖动：透镜跟手，位移按格宽折算；速度驱动拉伸 —— 顺着运动方向最多拉长 20%，横向收一点
  - 松手：弹到最近一格；**放大要等位置进到 2.5% 行程以内才收**（超时 800ms 兜底），
    这样「拖过去」和「落定」是一个连贯动作，不是滑一下再单独缩一下
- **底栏位置改成每帧跟官方底栏对齐**。以前只靠全局布局回调更新，而抖音展开个人页侧栏时
  底栏是靠 translation 滑过去的、不触发布局，玻璃就一直停着等下一次布局 ——
  看起来就是「点展开之后 dock 慢半拍才移过去，回退的时候也一样」。现在动画里的每一帧都跟。
- **换了一套图标**：从 1.8dp 的细线描边换成 24dp 实心剪影（房子 / 两个人 / 气泡 / 头肩，
  ＋ 换成实心十字）。线条在玻璃上又细又虚，放大当透镜时更糊；实心的轮廓厚实、放大也立得住。
- **修「dock 上面多出一块玻璃」**：挂在一整行上的那块玻璃是按行坐标算位置的，
  行一变高变矮、或者宿主换页时把同一批控件搬去别处，它就会漏到行外面（正好落在 dock 上方）。
  现在每块玻璃都带分区校验 —— 顶栏的只准出现在屏幕上方三分之一、底部的只准在下半部分，
  越界直接不画；画之前还 clip 到自己的控件范围内，绝不会漏到别的地方去。
- **修顶栏三块粘成一条**：三块玻璃左右各内缩 5dp，块与块之间的缝看得见了。
- **修「点进搜索页玻璃框还在」**：顶上那一行如果整条就是个可见的输入框（搜索页的搜索框），
  就不挂玻璃，交给抖音自己的输入态。切回来结构变了会自动挂回去。
- **修玻璃时有时无**：单帧判死改成连着 3 次才拆（切页动画中间有几帧尺寸是 0，会误杀）；
  宿主重设底色后的补装冷却从 1 秒降到 0.22 秒；结构重扫从 4.2 秒一次提到 1.3 秒一次；
  每格都重新对齐一次位置，宿主自己动的时候玻璃跟着动。

### 0.0.4
- **修黑块和残影（0.0.2 起的根）**：上一版为了让玻璃底下透出来，把底栏附近容器的背景
  直接设成 `null`。那些容器切页之后还是同一个对象，背景没了就再没人还回来 ——
  表现就是「打开别的界面还有黑块」「好多残影」。这一版**一个别人的背景都不碰**，
  只藏官方底栏那一条的画面。
- **修 dock 整条消失**：去掉那个「两秒半没画出来就把官方底栏还原」的守护 ——
  它在玻璃被收起的情况下会误杀，用户看到的就是 dock 突然变回官方原样、模块像没生效。
  现在只有「玻璃可见却一帧都没画出来」才会还原，画出来过一次就永久放手。
- **「被整页盖住就收起玻璃」不再误杀**：要连续几次都判成被盖住才收；
  并且遮挡者必须自己铺了一层底（真浮层），透明的信息流容器不再算遮挡。
- **玻璃收起时官方底栏一定露着**，绝不会留一条空白。
- **页面销毁时收尾**：把玻璃层拆掉、官方底栏透明度还原 —— 治残影。
- **顶栏 / 聊天页改成新的一套分组玻璃**（只换底色，不改层级、不改布局、不改透明度）：
  - 顶栏：**左一块、中间各种控件合成一块、右一块**
  - 聊天页底部：**输入条一块、右边三个控件一块**
  - 聊天顶栏：**返回一块、头像名字一块、右侧一块**
  - 中间那几个控件如果直接摊在整行上、没有共同容器，就挂整行的一块玻璃、只画那一组范围，
    照样是一整块，不会碎成几个小胶囊。
- **宿主把底色重设回去会自动补回来**（每 0.7 秒看一次）—— 之前「用着用着就不生效」就是这个。
- 背景采集改成几块玻璃轮流重采，不再同一时刻各画一遍整棵界面树（省电、不掉帧）。
- 后台刷新用弱引用，不再把界面钉在内存里。

### 0.0.3
- **修底栏整条消失**（0.0.2 最严重的问题）。上一版新加的「被整屏页面盖住就把玻璃收起来」
  判据太松：只看兄弟节点够不够大，抖音首页跟底栏同父的信息流容器每帧都满足，
  玻璃一挂上就被设成 GONE；紧接着 2 秒看门狗一看没画出来，又把官方底栏还原。
  用户看到的就是「dock 回到官方原样，模块没生效」。
  现在要求兄弟节点**矩形真的整个盖住底栏**、且是**有内容的整屏页面**才算被盖住。
  → 这一条跟「抬高扩大」无关，布局参数只是观感，不影响显示。
- **藏官方底栏的顺序改了**：玻璃真的画出第一帧之后，才把官方底栏藏起来；
  1.5 秒还没画出来就先让官方底栏露着兜底，绝不给你一片空白。
- **看门狗不再误杀**：玻璃是「我们自己收起来的」不算失败（底栏被宿主藏了、
  或被聊天页盖住），不会两秒后把 dock 弹回官方。等待上限放宽到 20 秒。
- **折射着色器挂掉不再整块消失**：AGSL 编不过 / RuntimeShader 不支持时退回磨砂。
- **顶栏切页残留**：点搜索进搜索页后，玻璃框不会再跟着浮在别的页面上。
  顶栏每 1.2 秒自检一次（还在不在主界面、有没有冒出可见的搜索框、有没有被整屏页盖住），
  不是主界面就把原来的底色还回去；回到首页再自动挂回来。
- 顶栏玻璃在宿主控件被藏起来 / 缩成 0 / 透明时不再绘制。
- 底栏玻璃加了上下边界的保护，抬高放大后不会被顶出屏幕裁掉。
