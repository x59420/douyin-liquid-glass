# dydock · 抖音底栏液态玻璃

面向抖音 Android 客户端的 LSPosed 模块：**把底部导航栏换成悬浮液态玻璃 Dock**，只动底栏这一块，其余界面保持抖音原样。

> 当前版本：**0.5.8**（versionCode 2508）
>
> 下载：**[GitHub Releases](https://github.com/x59420/douyin-liquid-glass/releases)**
>
> 推送到 `main` 且构建成功后，GitHub Actions 会自动出包并发版。

## 这一版改了什么（0.5.8）

本版针对「抖音出现启动画面后闪退」做启动钩子收敛：

- 移除重复的 `Instrumentation.callActivityOnResume` 安装入口，只保留 `Activity.onResume` 完成后的统一入口，避免同一个 Activity 在恢复时被两套 Hook 重复处理。
- Dock 安装前增加 Activity 生命周期检查，已结束或已销毁的页面不再进入窗口与视图处理。
- 本次不改 Dock 的形状、玻璃材质、折射 / 色散 / 高光 / 模糊 / 圆角 / 尺寸，也不删 Dock 功能。

> 这是针对启动阶段风险的保守修复，尚未拿到真机崩溃堆栈，因此不能宣称已确认唯一根因；需要安装测试版验证。

这一版只修行为问题，**Dock 的形状、玻璃材质、折射 / 色散 / 高光 / 模糊 / 圆角 / 尺寸一个都没动**。
下面每一条都是从运行日志里对出来的，不是猜的。

1. **Dock 出来一下就消失、反复闪（主要根因）**
   0.5.6 让位给玻璃时，把原生底栏的 alpha 设成 0；可「原生底栏该不该显示」这条判据又去读 alpha，
   读到的正是我们自己写的 0，于是判成「宿主把底栏藏了」→ 收起玻璃 → alpha 还原成 1 → 下一帧又判可见 → 玻璃再出来。
   日志里 **68 次「底栏隐藏」/ 53 次「底栏恢复显示」** 就是这个死循环。
   现在本模块自己改过的 alpha 全部单独登记（`SelfMask`），判可见性时按**原值**算；清遮罩时也绝不碰底栏的祖先链。
   外面还加了一道：不可见要连续 8 帧（约 130ms）才算，转场里的单帧抖动不会再把玻璃收掉。

2. **评论区 / 他人主页返回后 Dock 不回来**
   两个原因一起修：
   - 侧栏滑动时抖音会把底栏横向平移，可见宽度只剩两百多像素，旧判据「不足一半就算被裁掉」直接判死；
     现在高度 40%、宽度 26% 就算还在，只要贴着底、没被整页盖住就正常显示。
   - 长按态的兜底以前是**一分钟**：宿主吞掉 UP 之后，这条「长按中」会一直占着隐藏理由。
     现在压到 2.5 秒，并且抬手 / 取消 / 返回 / 回到前台都会立刻清。

3. **长按倍速时 Dock 闪一下**
   长按状态有两个来源（宿主回调 + 按住 240ms 的触摸判定），真机上这两个源会交替成立；
   而页面里「有没有视频层」是 240ms 扫一次，某一帧没扫到就返回 false → Dock 被放出来一帧又收回去。
   现在进过一次倍速就**锁存**，只认抬手 / 取消 / 返回 / 2.5 秒无触摸来解除，不再看页面扫描结果。

4. **底部背景透明不生效**
   宿主重建底栏会把那条底色重新铺回来，以前 1.2 秒才复查一次，肉眼就是「一直不生效」。
   现在 400ms 复查；同时清理弹层时跳过了底栏祖先链（以前误清祖先也会让整条底栏跟着消失）。

5. **原生弹层 / 菜单背景透明（新增）**
   底部弹出的菜单、分享面板自己铺的那层纯色底，现在也会清掉。判据故意保守：
   贴底、宽 ≥ 屏宽 90%、高在屏高 18%–62%、背景必须是纯色（`ColorDrawable`）、
   **里面不能有输入框**（所以评论区不会被误清）；只清 `background`，内容、点击、透明度都不动。
   设置里可以单独关掉。

6. **取视频背景会变黑**
   抖音的视频是受保护的 `SurfaceView`，`PixelCopy` 直接失败（日志 `code=1`），采到的是 luma=0 的黑帧。
   现在抓不到画面时，用**内容树的主色**垫一层不透明底，玻璃透出界面自身的颜色，不再是一块死黑。
   正常能采到画面的页面完全不受影响。设置里可以单独关掉（关掉就是原来的黑玻璃）。

7. **设置里切换深浅模式闪退**
   - `DockSettingsActivity` 加了 `configChanges="uiMode|..."`：系统换深浅色时不再重建 Activity；
   - 主题切换推到**下一帧**再改快照，避免点击回调里同帧换掉整套 palette / 图层背板（旧背板在绘制中被回收就会崩在渲染线程）；
   - 读系统深浅色失败时按深色兜底，不让整页崩。

8. **顺手**：状态栏透明被宿主改回时，日志从每次一条降成 5 秒一条（日志文件不再被刷爆），行为不变。

新增设置项（「行为」分组）：**底部背景透明**、**弹层 / 菜单背景透明**、**视频背景兜底**。
默认全开；关掉就退回原来的行为。

> 没有动外观相关的任何默认值：透明度 100%、不隐藏背景、跟随系统、尺寸和材质与 0.5.6 一致。

## 功能

- 四个导航图标装在一块长条玻璃里，右边是独立的圆形「＋」，整组水平居中
- 默认 64dp 高、每格 76dp 宽、左右 24dp 安全边距、离底 8dp（都可在设置里调）
- 玻璃背景实时采 Dock 背后那块真实画面（内容树 + 视频层），交给 Miuix 的 blur / lens 渲染
  - Android 13+：真折射（RuntimeShader）
  - Android 8–12：磨砂回退，没有折射与泛光
- 未读角标、按压泛光、左右拖动 + 弹簧回位
- 点击转发给抖音原生导航项（取的是当前底栏节点，宿主重建后照样点得动）
- 显隐跟随原生底栏：原生藏就收、原生出就出（另加长按倍速、双指清屏时收起）

## 安装

1. 从 [Releases](https://github.com/x59420/douyin-liquid-glass/releases) 下载最新 APK
2. 安装，LSPosed 里启用 **dydock**
3. 作用域勾选抖音（`com.ss.android.ugc.aweme`）
4. 强制停止抖音，重新打开

**设置入口**：抖音「我的」→ 右上角菜单 → **dydock**（在「设置」左边）。

设置分四组：

| 分组 | 可调 |
| --- | --- |
| 外观 | 深浅模式（跟随系统 / 浅色 / 深色）、玻璃透明度、隐藏玻璃背景、启用开关、「＋」、文字标签 |
| 行为 | 底部背景透明、弹层 / 菜单背景透明、视频背景兜底 |
| 尺寸 | Dock 高度、单个图标宽度、左右留白、离底部距离 |
| 调试 | 记录日志 |
| — | 恢复默认尺寸 |

改完一秒内生效，不用重开抖音。

## 只改这些地方

| 区域 | 行为 |
| --- | --- |
| 四个主 tab 的底部导航栏 | 替换成液态玻璃 Dock |
| 顶栏、搜索栏、信息流、评论区、聊天页、个人页、弹窗 | 保持抖音原样 |
| 底部深色底 / 渐变遮罩、状态栏 / 导航栏 | 透明化（见上文） |
| 长按倍速、清屏、评论页、整屏覆盖页 | Dock 收起，退出后恢复 |

原生 Dock 始终隐藏，只用于转发点击和读角标。

> 抖音会持续更新，内部结构可能变化；识别逻辑不保证兼容所有版本，效果需在目标设备上验证。

## 系统要求

- Android 8.0（API 26）及以上
- LSPosed（Xposed API 82 或兼容接口）
- 抖音 Android 客户端

## 构建

需要 JDK 21、Gradle 9.7.1、Android SDK Platform `android-37.0` + Build Tools `37.0.0`。

```bash
ANDROID_HOME=/path/to/android-sdk bash build.sh
```

`build.sh` 会补 Xposed API jar、取回签名口令、跑 `assembleRelease`，产物在 `out/dydock-<版本>.apk`。

三个必须注意的点：

- `iso/**` 是按名字反射加载的，`app/proguard-rules.pro` 里要 `-keep`（连它引用的 `ksu/**`），否则 R8 会把玻璃层裁光，表现是「装了没反应」。
- `versionCode` 必须大于设备上已装的版本，否则安卓以「降级」为由拒绝覆盖安装。
- `keystore/dydock.jks` 必须一直用同一份，换了就不能覆盖安装。
